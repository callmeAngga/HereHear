# HereHear

HereHear adalah aplikasi mobile Android yang dirancang untuk membantu pengguna mengekspresikan perasaan melalui jurnal harian, dilengkapi dengan deteksi otomatis terhadap potensi kecenderungan bunuh diri menggunakan analisis teks.

## 🚀 Fitur
- 📓 Penulisan jurnal harian
- 🧠 Analisis sentimen untuk mendeteksi kecenderungan bunuh diri
- 🔐 Autentikasi pengguna dengan Firebase
- 📰 Rekomendasi artikel dari Open API
- 💾 Penyimpanan lokal dengan Room dan backend dengan Cloud SQL

## 🛠️ Teknologi yang Digunakan
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Room Database
- Cloud SQL
- Open API Integration

## 📦 Status Proyek
✅ Versi awal telah selesai dan dirilis pada Desember 2024

## 📲 Instalasi

1. Clone repositori
   https://github.com/callmeAngga/HereHear.git
3. Buka proyek di Android Studio
   - Pastikan menggunakan Android Studio versi terbaru
   - Pilih opsi "Open an existing project"
   - Sinkronisasi Gradle
   - Tunggu hingga semua dependency berhasil diunduh
4. Jalankan aplikasi
   - Pilih emulator atau perangkat fisik
   - Klik tombol Run atau tekan Shift + F10
